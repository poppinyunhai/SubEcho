SubEcho 是一个轻量的 Chrome 扩展：读取 YouTube 当前显示的字幕，通过小米 MiMo 生成自然语音，并跟随视频暂停和跳转。

看英文课程、技术分享或访谈时，开启 YouTube 英文字幕，在 SubEcho 中选择 AI 翻译模式，就可以边看视频边听中文配音。无需自建服务器，也无需构建项目。

> **需要自己的 MiMo API Key。** 支持直接朗读与英文字幕 AI 翻译两种模式；配音会有网络和语音合成延迟，不保证严格同声。

## 功能

- **一键设置字幕**：点击「一键开启中文字幕」，自动开启 CC，优先选择现成的简体中文字幕，否则尝试 YouTube 中文自动翻译。AI 模式也提供「一键开启英文字幕」。

- **AI 翻译配音**：英文字幕由 MiMo 文本模型翻译成中文，再交给 MiMo TTS 朗读；支持 Flash / Pro 模型，复用同一个 Key。
- **上下文与双语对照**：翻译参考前四段字幕，页面显示当前英文原文与中文译文。

- **流式配音**：收到 MiMo 音频片段后开始播放，无需等待整段生成完毕。
- **自然朗读**：采用平和、放松的表达，减少播音腔、夸张情绪和刻意重音。
- **字幕去重与合并**：处理逐字追加和滚动字幕，减少重复朗读。
- **播放同步**：视频暂停时暂停配音，跳转进度时取消旧请求与旧音频。
- **可调音色与语速**：提供冰糖、茉莉、苏打、白桦四种中文音色，支持 1.0×–1.5× 配音速度。
- **原声控制**：降低视频原声音量；停止后恢复开启前的音量。
- **状态提示**：在页面显示等待、合成、朗读或错误状态，支持一键停止。
- **故障恢复**：网络故障和限流自动退避重试，避免无限重试或整句重复播放。

## 快速开始

### 1. 安装扩展

当前通过本地加载使用，尚未发布到 Chrome Web Store。需要 Chrome 116 或更新版本。

1. 下载本仓库源码 ZIP 并解压，或克隆仓库到本地。
2. 打开 `chrome://extensions`，开启右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择包含 `manifest.json` 的项目文件夹。

安装后，刷新已经打开的 YouTube 页面。无需运行 `npm install`。

### 2. 配置 MiMo

1. 在 [小米 MiMo 开放平台](https://mimo.mi.com/) 获取自己的 API Key，并确认账号可以调用 `mimo-v2.5-tts`。
2. 点击 Chrome 工具栏的 SubEcho 图标，填写 Key。
3. 选择音色、配音语速和原视频音量。
4. 选择「直接朗读当前字幕」或「英文字幕 → AI 中文翻译 → 配音」。AI 模式可选择 Flash 或 Pro 翻译模型，需要 Key 有对应模型权限。
5. 阅读隐私说明，勾选发送同意；AI 模式还需同意发送前几句上下文。

想听得更自然，可以先试 **1.0×** 语速；想减少配音积压，可以试 **1.15×**。

### 3. 开始听字幕

1. 打开 YouTube 视频并开启 **CC 字幕**。
2. 可以先点击插件顶部「一键开启中文字幕」直接设置中文，并自动切换为直接朗读模式。AI 模式中点击「一键开启英文字幕」则设置英文并切换为 AI 翻译模式。快捷设置支持中英文 YouTube 菜单；无可用字幕时会显示原因。
3. **AI 翻译模式**：选择英文字幕（手动或自动生成），不要开启 YouTube 中文自动翻译。**直接朗读模式**：选择要朗读的字幕；听中文时可选择中文字幕或中文自动翻译。
4. 点击 SubEcho 的「开始配音」，播放视频。
5. 如果页面出现「点击启用配音声音」，点击一次允许声音播放。

暂停视频会暂停配音，拖动进度会清除旧配音。点击页面或弹窗中的「停止」结束配音。

## 工作方式

```text
YouTube 当前字幕
    ↓ 稳定检测、去重、短句合并
扩展后台 → [可选：MiMo 英译中] → MiMo TTS API
    ↓ 流式音频
页面播放 → 跟随暂停、跳转和视频切换
```

翻译使用 `mimo-v2.6-flash` 或 `mimo-v2.6-pro`，关闭深度思考以减少等待；配音使用 `mimo-v2.5-tts`，音频使用 24kHz PCM16。扩展后台负责 API 请求，页面内容脚本负责字幕读取和播放。

为了避免延迟持续累积，等待队列最多保留三段，并丢弃超过 12 秒的旧字幕。网络或限流错误在音频开始前最多重试两次；已播放部分内容的句子不会整句重试。临时失败后等待 10 秒，再继续后续字幕。

## 隐私与费用

- Key 保存在当前 Chrome 扩展的本地存储中，不通过 Chrome Sync 同步，也不会发送给项目作者。
- 开启配音后，当前字幕、AI 模式的前四段上下文，以及请求认证信息通过 HTTPS **直接发送给小米 MiMo**。翻译和语音合成会分别使用你自己的账号额度。
- 字幕与生成音频仅在运行时内存中使用，不保存历史记录。
- 项目没有作者后端、广告、分析或追踪 SDK。
- 可以在弹窗删除本地 Key；如需撤销凭据，请在 MiMo 平台操作。

完整说明见 [隐私政策](PRIVACY.md)。请不要把个人 Key 写入源码、Issue、截图或 Git 提交。

## 当前限制

- **质量仍需对比**：AI 翻译不保证始终优于 YouTube 翻译；英文自动字幕识别错误也会影响译文。直接朗读模式仍使用原字幕语言。
- **依赖可见字幕**：未开启字幕或视频没有字幕时无法配音，不提前获取完整字幕。
- **存在延迟**：字幕稳定等待、翻译、网络、合成及音频队列都会带来延迟。连续高速讲话时可能跳过积压字幕。
- **优先支持普通录播视频**：直播和 Shorts 尚未验证。
- **依赖 YouTube 页面结构**：页面结构变化可能需要更新字幕选择器。

## 常见问题

**开启后没有声音？**  
确认视频正在播放、CC 已开启、页面确实显示字幕。若有启用声音按钮，请点击它；检查插件状态提示及 MiMo Key、模型权限和账号额度。

**为什么读的是英文？**  
确认已选择 AI 翻译模式并保存设置；该模式要求使用英文字幕。直接朗读模式按当前字幕语言朗读。

**声音落后于视频？**  
可以适当提高配音语速或降低视频速度。当前版本不提前生成后续字幕的语音，因此无法完全消除延迟。

**更新后没有变化？**  
在 `chrome://extensions` 点击 SubEcho 的重新加载按钮，再刷新 YouTube 页面。

**请求失败 402？**  
MiMo 官方定义为账户余额不足。当前扩展使用按量 API，请在 MiMo 控制台检查对应账户余额。Token Plan 订阅 Key 与按量 Key、接口不能混用。余额问题解决后停止再开启配音。

**API Key 无效或没有模型权限？**  
修正 Key 或账号权限后保存设置。认证错误不会自动重复请求；临时网络错误会自动恢复。

## 开发与打包

运行扩展无需依赖安装。开发检查需要 Node.js 22；打包另需 Python 3。

```sh
npm run check       # JavaScript 语法检查
npm test           # 自动化测试
npm run package    # 生成 Chrome 扩展 ZIP
```

安装包输出为 `dist/subecho-0.3.2.zip`，只包含运行文件、隐私政策页和图标。GitHub Actions 会自动执行检查、测试及打包。

```text
background.js      MiMo 请求、流式解析和重试
translation.js     上下文翻译、校验和取消
captions.js        播放器字幕菜单快捷设置
content.js         字幕读取、播放同步和页面状态
core.js            字幕处理、SSE 和 PCM 工具
popup.*            设置与配音开关
icons/             扩展图标
scripts/package.py 发布打包
tests/            自动化测试
```

测试覆盖字幕增量去重、SSE 分片、PCM 转换、重试边界、发送同意、暂停、跳转取消和音量恢复。真实音色、延迟和 YouTube 页面兼容性需要实机验证。

翻译暂时按当前可见字幕处理，不预取完整字幕，也不提前翻译尚未显示的内容。建议先试普通英语录播视频并对比翻译质量。

GitHub 和 Chrome 商店发布步骤见 [发布指南](RELEASE.md)。
